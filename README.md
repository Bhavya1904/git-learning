# Git Learning Sandbox

This folder is your safe space to learn Git. Break things freely — that's the point.

## Phases
1. **Foundations** — Setup, mental model, first commit
2. **Daily Workflow** — status, add, commit, diff, log
3. **Branching & Merging** — branches, merge conflicts
4. **Remotes (GitHub)** — push, pull, PRs
5. **Undo & Recovery** — reset, revert, stash, reflog
6. **Advanced** — rebase, cherry-pick, bisect, tags
7. **Team Workflows** — PRs, code review, interview prep

## Rule
One phase at a time. Practice each before moving on.
